# تأسيس النطق — Flutter v1.1

تطبيق عربي RTL لأطفال KG لتأسيس الحروف، الأصوات، الكلمات، والتدريب على النطق.

## الموجود فعليًا
- 28 حرفًا عربيًا و84 مثال كلمة.
- KG1 مبسط: مثالان داخل درس الحرف + 28 كلمة أساسية + صوت الحرف بالفتحة.
- KG2 موسع: 3 أمثلة للحرف + جميع الـ84 كلمة + الفتحة والضمة والكسرة لكل حرف (84 تدريب صوتي).
- نطق عربي TTS، تسجيل صوت الطفل، وإعادة تشغيل التسجيل.
- 3 ألعاب تعليمية مع نتائج ونجوم.
- الألعاب تستخدم فقط الحروف المفتوحة للطفل بدل القفز لمحتوى لم يتعلمه.
- حفظ محلي: التقدم، النجوم، المستوى، الهدف اليومي، الاستمرار، محاولات النطق، ودقة الألعاب.
- سجل نشاط آخر 30 يومًا ولوحة ولي الأمر تعرض آخر 7 أيام.
- Parent Gate قبل الإعدادات.
- بدون إعلانات أو Analytics في هذه النسخة.

## بناء APK على Windows — أمر واحد
شغّل:

```powershell
powershell -ExecutionPolicy Bypass -File .\INSTALL_FLUTTER_AND_BUILD.ps1
```

السكربت يحمّل أحدث Flutter Stable من manifest الرسمي، يتحقق من SHA256، يجهز Android project عند الحاجة، ثم يشغّل `pub get` و`analyze` و`test` ويبني Release APK. Android SDK يجب أن يكون موجودًا على الجهاز.

## Linux
```bash
./tool/install_flutter_linux.sh
```

## GitHub Actions
الملف `.github/workflows/android-apk.yml` يبني APK تلقائيًا على GitHub Actions باستخدام Flutter 3.47.5.
